Un solo lugar para conectar tu bot

Configura las variables en .env y reinicia el servidor. Las claves nunca se muestran ni se guardan en el navegador.

TELEGRAM_BOT_TOKEN=token_de_BotFather
LLM_API_KEY=clave_de_tu_proveedor
LLM_BASE_URL=url_compatible_de_tu_proveedor
LLM_MODEL=modelo_disponible_en_tu_cuenta

Conserva las variables existentes. El acceso al panel usa el usuario admin y el archivo local .dashboard-password, no una variable adicional.

La versión base responde a notas de voz solicitando texto; la transcripción requiere integración adicional. Publica una única instancia del servidor con disco persistente.
